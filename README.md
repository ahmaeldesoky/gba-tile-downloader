# GBA Tile Downloader

This script automates downloading the [GlobalBuildingAtlas LoD1](https://github.com/zhu-xlab/GlobalBuildingAtlas) building tiles for a designated polygon (`.gpkg`), clips them to that polygon, and saves the result.

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python download_tiles.py
```
